## Scope

Find differences from Java 42.9 with the differential fuzzer; fix none of them.

1. Measure the present state: every family of `fuzz.FAMILIES`, 1000 seeds, `--keep-going`,
   against the Java reference, with the known findings set apart.
2. Widen generation, strictly by addition, to what the engine gained since the wide fuzzer:
   row variables, column arrays and fixed-distance reads, arithmetic on array columns, time
   literals with a zone, aggregation with initial groups, partitioned tables, ring tables,
   keyed transpose, a multi join without match columns, a range join without aggregations,
   the rolling formula and count where operators of `update_by`, and column statistics. A
   seed of an existing family keeps naming the scenario it named.
3. Run the new families for 1000 seeds each, minimise every difference to a scenario file,
   classify it, and write it up in `tasks/4.20-fuzz-findings-2.md`. A known entry or a
   generator restriction is added only for a finding that is written up, and names it.

Not part of it: engine fixes, changes to the comparison of anything that existed, and the
removal or narrowing of a restriction or known entry.
