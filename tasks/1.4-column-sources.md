## Scope

Implement `ColumnSource` for every `ColumnType`: an immutable flat source (Arrow array indexed by position), a writable sparse source addressed by row key that records previous values for the current cycle, and a redirected source (row key to inner key). Nulls are validity bits. Provide conversion to and from Java's sentinel null values for the wire layer, with the sentinel constants taken from `QueryConstants`.

## Notes

- `WritableSource` and `WritableRowRedirection` learn the time from a `Clock` handle
  (`oxhaven_column::Clock`, implemented for `Arc<dyn UpdateGraph>`) given to
  `start_tracking_prev`. Mutating calls take no step. Previous values are used only while the
  clock is in the updating phase of the step they were recorded in, so no end-of-cycle callback
  is needed.
- A write made while the clock is idle records no previous value, as the `ColumnSource`
  contract requires (idle: previous equals current). Java records it and keeps the old value
  readable until the end of the next cycle (`IntegerSparseArraySource#shouldRecordPrevious`).
- Writing one row is `fill` with a one-element array; there is no per-type scalar setter.
- `apply_shifts` takes the pre-shift rows to move, as Java's callers pass
  `prevRowSet ∩ range`; values stored at keys outside those rows stay put.
- `RedirectedSource` is read-only. Java's `WritableRedirectedColumnSource` also writes through
  the redirection; a writer here redirects the keys and fills the inner `WritableSource`.
- `sentinel::nulls_to_sentinels` and `sentinels_to_nulls` leave `Boolean` and `String` arrays
  unchanged: Java's Barrage writers for them are not `dhNullable`. `boolean_to_bytes` and
  `bytes_to_boolean` give the -128/0/1 byte form of `ReinterpretUtils`.
