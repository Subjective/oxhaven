## Scope

A listener that can be attached to any `Table` and checks, every cycle: the update passes `TableUpdate::apply_to` against the previous row set and yields the current row set; previous values read during the cycle equal the values captured at the end of the last cycle; unmodified rows and unmodified columns did not change; and, given a recompute closure, the incremental table equals a from-scratch recompute. Include tests where each kind of seeded bad update is caught.
