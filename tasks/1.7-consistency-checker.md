## Scope

A listener that can be attached to any `Table` and checks, every cycle: the update passes `TableUpdate::apply_to` against the previous row set and yields the current row set; previous values read during the cycle equal the values captured at the end of the last cycle; unmodified rows and unmodified columns did not change; and, given a recompute closure, the incremental table equals a from-scratch recompute. Include tests where each kind of seeded bad update is caught.

## Notes

- Also delivers task 0.12, the reference implementations of the contracts, in the same crate.
- No `unported!` calls.
- The checker collects problems and reports them from `verify()` / `assert_consistent()`,
  which a test calls after each `run_cycle()`. The contracts have no end-of-cycle hook, so the
  between-cycle checks (silent changes, previous equals current, recompute) cannot run by
  themselves.
- Contract gap: a listener cannot tell that its table has notified while its own delivery is
  still queued, so `Dependency::satisfied` cannot be exact for a listener written against
  the contracts alone. The checker and `Recorder` answer too early in that window; nothing
  should wait on them.
