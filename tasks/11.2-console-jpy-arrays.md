## Notes

### Done

- `python/jpy.py`: arrays of the eight primitive types (kept in an `array.array` of jpy's C
  type, so `memoryview` and `numpy.frombuffer` read them), of `String`, `Boolean`, the
  boxed numbers, `Object`, `org.jpy.PyObject`, the `java.time` classes and calendar
  classes the package has, and arrays of them. Their classes are those `jpy.get_type`
  hands out, with jpy's names and bases; length, positions, iteration, assignment, Java's
  conversions and texts for each element type, `None`, the out-of-bounds errors, equality
  as identity, `equals`, `hashCode`, `toString`, and none of Python's sequence methods.
- `jpy.cast`: to the object's own class, the object; to a class it cannot be an instance
  of, `None`, by the Java language's rules for arrays and the final classes; a Python
  value is jpy's `ValueError`. `jpy.convert` to an array class and to the classes of
  `java.time` the package has.
- `deephaven.dtypes.array` and `_instant_array` return these arrays; so do the array
  cells the package reads from tables (`data.rs`). `InputColumn` checks the column type
  before the values, so a type the engine cannot hold is refused by that name first.
- A variable holding an array is the array in every row of a formula
  (`FormulaValue::Array`, an external function without arguments): `X = arr`, `arr[i]`,
  `arr.length`, `sum(arr)`, `ungroup`. plotly-express's `dx.data.gapminder()` ticks, with
  Java's columns and first rows (`docs/FIGURES.md`, "After task 11.2").
- About 800 expressions were run on jpy 2.2.0 in the reference and here; the tests hold
  them. Differences and reproduced oddities are in `docs/CONSOLE.md`, "Java arrays".

### Still not ported

- Arrays of any other class (`java.util.List[]`, `BigDecimal[]`, `Number[]`,
  `Comparable[]`, `CharSequence[]`, `java.nio.ByteBuffer[]`, `Table[]`), even of nulls:
  `not ported: <class>[]: jpy.array`. Elements of those come back as Java objects the
  package has no value for.
- A cast to a superclass (`Object`, `Object[]`, `Serializable`, `Comparable`), which in
  jpy gives an object with that class's methods only, and a cast whose answer needs
  Java's class hierarchy (`java.util.List`, `Number`): `not ported: <class>: jpy.cast of a
  <class>`. jpy answers `None` for some of these, an object for others.
- `jpy.convert` to any class but an array or a `java.time` class the package has: jpy
  gives a Java object (a `java.lang.String` object for a `str`), which the package has no
  value for.
- `getClass`, `wait`, `notify`, `notifyAll` and `jclass` of an array.
- An array of `boolean`, `Object` or another class the engine has no column type for, in a
  formula. An array variable in a formula a gRPC client sends.

### Handover

- An array in a formula is read when the formula is compiled; Java's column holds the
  array itself and shows a later change to it. Listed in `docs/CONSOLE.md`.
- `isinstance(a, collections.abc.Sequence)` is true for a primitive array here (Python
  registers `array.array`), false in jpy; a `memoryview` of one is writable here,
  read-only in jpy.
- `PARITY.md` A10 now says the module carries out the classes `docs/CONSOLE.md` lists and
  refuses the rest, as the owner approved; no other allowed difference was touched.
