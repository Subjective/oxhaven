- **Status:** in review
- **Branch:** `task/15.5-docker-image`
- **Needs:** nothing open
- **Owns:** `docker/` (new), `.dockerignore`, the "Run it" section of `README.md`, a CI job that builds the image

- **Read:** `README.md` "Run it with the web IDE", `scripts/extract-web-root.sh`, `docs/CONSOLE.md` (embedded Python,
  virtual environments), Deephaven's own image's options (`START_OPTS`, the PSK, port 10000, `/data`)

## Scope

Owner's go-ahead (25 November). One command to try Oxhaven: `docker build` then
`docker run -p 10000:10000 oxhaven` opens the web IDE with a Python console, pandas/numpy/pyarrow available and
`deephaven-plugin-plotly-express` installed. Multi-stage build (release binary with the `python` feature, a slim
runtime image with Python and a venv), the web IDE files extracted at build time, notebooks in a volume, the PSK
from an environment variable as Deephaven's image takes it (or a random one printed to the log). Only Apache-2.0/MIT
for anything added to the repository; base images are not vendored.

Add a CI job that builds the image (no push, no registry, no secrets). Publishing to a registry is not part of
this task: it publishes outside the repository and needs the owner.

## Verification

Build the image, run it, and run `oracle/ide/ide-test.js` (or the subset that needs no build tools) against it; a
`pydeephaven` session that makes and reads a table. Report image size and start time.

## Notes

- Built locally (Docker 29.9.2, `CARGO_BUILD_JOBS=2`, 4 cores) in 10 min 24 s from an empty
  cache. The image is 1.04 GB on disk, 226 MB compressed: the binary 64 MB, `/opt/venv`
  436 MB, the web files 143 MB, the rest the Python base image.
- `docker/smoke.sh`: the IDE answers 1.1 s after `docker run`.
- `node oracle/ide/ide-test.js --url http://127.0.0.1:<port> --psk <key>` against
  `docker run ... oxhaven --demo-tables`, routes panels, iframe, jsapi, console, notebook,
  log, grid, errors, rollup, tree and format: all passed. `pydeephaven` 42.9 made and read
  a table, and a console script imported numpy, pandas and pyarrow and made a `dx.line`
  figure. HTTPS with a mounted certificate as `docker/README.md` shows: `/ide/` answered
  200 over HTTP/2.
- The server handles only SIGINT, so the image sets `STOPSIGNAL SIGINT`; `docker stop` then
  ends it at once instead of killing it after 10 s.
- The CI job pulls `python:3.13-slim-bookworm` from Docker Hub without a login, so Docker
  Hub's anonymous pull limit can fail it. Locally Docker Hub answered 429, and the base came
  from `mirror.gcr.io` with the agent proxy's certificate added (`--build-arg PYTHON_IMAGE`).
