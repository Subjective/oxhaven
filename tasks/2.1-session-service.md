## Scope

Flight handshake and the session service: anonymous and pre-shared-key auth, session tokens and refresh, export tickets with their state machine (pending, exported, released, failed, dependency failed), `ExportNotifications`, release and close. Ticket byte layouts must match Java exactly.

## Gate

```bash
cargo test -p oxhaven-server session && oracle/bin/harness client-smoke session --url "$OXHAVEN_URL"
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`.

## Notes

- Besides `src/session/`, this task added the server skeleton in `src/lib.rs` (`ServerState`,
  `serve`) and `src/main.rs`. A service task adds its service in `ServerState::routes` and, if it
  owns a kind of ticket, its `TicketResolver` in `ServerState::new`.
- `NewSession` is not ported and answers `UNAUTHENTICATED`. In the reference it gives any caller
  a superuser session without credentials (`SessionServiceGrpcImpl#newSession`), which would
  bypass the pre-shared key. Needs an owner decision; pydeephaven does not call it.
- Flight calls other than `Handshake` answer `UNIMPLEMENTED` from `HandshakeOnlyFlight`; the
  Flight task replaces that type and keeps calling `session::handshake`.
- Not ported, because nothing in this task's scope reaches them: `ExportObject#release` (the
  deferred release used by the object service), `SessionState#newFailedServerSideExport`,
  resolving and publishing by Flight descriptor and `ExportTicketResolver#flightInfoFor` (they
  need the Flight schema encoding), the abnormal-termination path `SessionService#onFatalError`,
  `SessionServiceGrpcImpl#insertCallHeader`, and `BasicAuthMarshaller`.
- The oracle half of the gate (`python oracle/run.py client-smoke session`) was not run: the
  harness does not exist yet.
