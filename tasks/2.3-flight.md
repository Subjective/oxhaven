## Scope

Arrow Flight `GetSchema`, `GetFlightInfo`, `DoGet` (snapshot of a table) and `DoPut` (upload a table). Schemas carry the same Deephaven metadata keys and values as Java. Capture schemas from the oracle for every `ColumnType` and assert equality; if `ColumnType::arrow_type` disagrees with Java, record it in Notes for a contract change.
