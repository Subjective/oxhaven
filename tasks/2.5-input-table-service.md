## Scope

`CreateInputTable` (append-only and keyed), `AddTableToInputTable` and `DeleteTableFromInputTable`. This is what lets the harness drive ticking scenarios against Oxhaven.

## Gate

```bash
cargo test -p oxhaven-server inputtable && oracle/bin/harness client-smoke inputtable --url "$OXHAVEN_URL" && oracle/bin/harness replay --url "$OXHAVEN_URL" --ops input_table --within input_table
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. `--within input_table` selects the scenarios that use input tables and no table operation.
