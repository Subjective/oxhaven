## Scope

The config service (authentication constants and configuration constants the web client reads), a gRPC-web transport on the same port, and the browser-streaming variants of bidirectional calls that the JS client uses in place of true bidi streams.

## Gate

```bash
cargo test -p oxhaven-server config transport
```

## Notes

The config service (`src/config/`) is done on the branch of task 2.2: `GetAuthenticationConstants` and `GetConfigurationConstants`. It leaves out `java.version`, `groovy.version` and `python.version`, which describe a runtime this server does not have. The gRPC-web transport and the browser-streaming calls are still open.

The gate command as written is refused by cargo, which takes one test name filter. `cargo test -p oxhaven-server config` runs the config tests.
