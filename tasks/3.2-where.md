## Scope

`filter` (structured conditions: compare, in, is-null, and/or/not, matches, contains) and `unstructured_filter` (formula strings through the expression crate). Build the static path first and get it through the gate, then the incremental path. Add the gRPC handler for these batch operations. Run every engine test with the consistency checker attached.

## Gate

```bash
cargo test -p oxhaven-engine filter && oracle/bin/harness replay --url "$OXHAVEN_URL" --ops where --within where,input_table && oracle/bin/harness fuzz --a "$JAVA_URL" --b "$OXHAVEN_URL" --ops where --seeds 10000
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The oracle harness does not cover structured filters (`filter`) yet, so this gate does not check it; that needs an oracle task first. `where` is the harness name for `unstructured_filter`.
