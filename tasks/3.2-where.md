## Scope

`filter` (structured conditions: compare, in, is-null, and/or/not, matches, contains) and `unstructured_filter` (formula strings through the expression crate). Build the static path first and get it through the gate, then the incremental path. Add the gRPC handler for these batch operations. Run every engine test with the consistency checker attached.

## Gate

```bash
cargo test -p oxhaven-engine filter && oracle/bin/harness replay --url "$OXHAVEN_URL" --ops where --within where,input_table && oracle/bin/harness fuzz --a "$JAVA_URL" --b "$OXHAVEN_URL" --ops where --seeds 10000
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The oracle harness does not cover structured filters (`filter`) yet, so this gate does not check it; that needs an oracle task first. `where` is the harness name for `unstructured_filter`.

## Notes

Built in `crates/oxhaven-engine/src/ops/filter/`: `unstructured_filter` (filter strings) and
`filter` (structured `Condition`s, with `normalize` and `print`). Not built: the gRPC handler
`crates/oxhaven-server/src/table/ops/filter.rs`, and so the harness half of the gate was not run.

`unported!` in this module:

- `io.deephaven.engine.table.impl.select.WhereFilterFactory#expandQuickFilter`: the structured
  `search` condition.
- `io.deephaven.engine.table.impl.select.FormulaParserConfiguration#extractParserAndExpression`:
  a filter string that starts with `<ObfuscatedParserAnnotation>`.
- `io.deephaven.time.DateTimeUtils#parseZonedDateTime`: an `Instant` literal in a zone other
  than UTC (`... UTC`, `yyyy-MM-dd UTC` and `...Z` are read).
- `io.deephaven.engine.table.impl.select.MatchFilter.ColumnTypeConvertorFactory#getConvertor`:
  a column type added to `ColumnType` later.
- `java.util.regex.Pattern#compile`: a `matches` regular expression outside the translated
  subset (see `pattern.rs`).
- `java.text.DecimalFormat#format`: a structured range literal that is a double of 2^53 or
  more, or exactly half way at the sixteenth fraction digit.
- `java.lang.Double#toString`: a subnormal double with one significant digit, in a printed
  structured condition.
- `java.lang.String#equalsIgnoreCase`: a supplementary character that has a case mapping, in
  `icase in`.
- `java.lang.Character#digit`: a non-ASCII digit in an integer literal.
- `jdk.internal.math.FloatingDecimal#parseHexString`: a hexadecimal floating point literal.

Not ported because nothing reaches them yet: `ShiftedColumnsFactory#where` (constant-offset
array access in a filter), `FilteredTable#doRefilter` (dynamic filters), filter push-down and
reordering, and the query scope lookups of `MatchFilter` and `RangeFilter`.

`java_doubles.txt`, `java_patterns.txt` and `java_routing.txt` next to the tests hold answers
of a JDK 21 for double printing, `java.util.regex` and the patterns of `WhereFilterFactory`.
