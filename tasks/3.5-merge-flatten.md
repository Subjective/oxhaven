## Scope

`merge` (row order is the order of the input tables, then each table's own order) and `flatten`. Build the static path first and get it through the gate, then the incremental path. Add the gRPC handler for these batch operations. Run every engine test with the consistency checker attached.

## Gate

```bash
cargo test -p oxhaven-engine merge && oracle/bin/harness replay --url "$OXHAVEN_URL" --ops merge --within merge,input_table && oracle/bin/harness fuzz --a "$JAVA_URL" --b "$OXHAVEN_URL" --ops merge --seeds 10000
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The oracle harness does not cover `flatten` yet, so this gate does not check it; that needs an oracle task first.
