## Scope

`aggregate` with sum, count, min, max, first, last and avg, keyed and unkeyed. Build the keyed state manager and the operator interface that task 4.1 extends: one generic implementation in place of Java's per-type operator classes. Group order and result types per PARITY.md. Build the static path first and get it through the gate, then the incremental path. Add the gRPC handler for these batch operations. Run every engine test with the consistency checker attached.

## Gate

```bash
cargo test -p oxhaven-engine agg && oracle/bin/harness replay --url "$OXHAVEN_URL" --ops agg_by --within agg_by,input_table && oracle/bin/harness fuzz --a "$JAVA_URL" --b "$OXHAVEN_URL" --ops agg_by --seeds 10000
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. `agg_by` is the harness name for `aggregate`; it covers `sum`, `count`, `min`, `max`, `first`, `last` and `avg`. The oracle harness does not cover any other aggregation yet, so this gate does not check it; that needs an oracle task first.
