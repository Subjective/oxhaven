## Scope

`natural_join`, `exact_join`, `left_join` and `multi_join`, with Java's duplicate-right-key error conditions. Build the static path first and get it through the gate, then the incremental path. Add the gRPC handler for these batch operations. Run every engine test with the consistency checker attached.

## Gate

```bash
cargo test -p oxhaven-engine join && oracle/bin/harness replay --url "$OXHAVEN_URL" --ops natural_join,exact_join --within natural_join,exact_join,input_table && oracle/bin/harness fuzz --a "$JAVA_URL" --b "$OXHAVEN_URL" --ops natural_join,exact_join --seeds 10000
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The oracle harness does not cover `left_join` and `multi_join` yet, so this gate does not check them; that needs an oracle task first.
