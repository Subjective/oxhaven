## Scope

In order, probing the Java reference for each type and operation before writing it, one
commit per piece:

1. `sort` and `sort_descending` on `LocalDate`, `LocalTime`, `Duration`, `ZonedDateTime` and
   `DayOfWeek`; `ZoneId`, `Period` and `Object` refused with Java's error.
2. Match filters (`=`, `!=`, `in`, `not in`) and range filters (`<`, `<=`, `>`, `>=`) in
   `where` on those types, with the literals Java's filter parser accepts for each.
3. Keys of those types in `natural_join`, `exact_join`, `join`, `agg_by`, `group_by` and
   `distinct`, and the `min`, `max`, `first`, `last`, `count_distinct`, `unique` and
   `sorted_first` aggregations where Java computes them.
4. If small: the types in the fuzzer's column generators.

At least one recorded scenario covers sort, filter and key use of these types.

Not in scope: sorting arrays and vectors (`ComparatorRegistry`), `BigDecimal` and
`BigInteger` sort keys, an `Object` column in filters and keys.
