## Scope

`snapshot` and `snapshot_when` with its initial, incremental and history options. Build the static path first and get it through the gate, then the incremental path. Add the gRPC handler for these batch operations. Run every engine test with the consistency checker attached.

## Gate

```bash
cargo test -p oxhaven-engine snapshot && oracle/bin/harness replay --url "$OXHAVEN_URL" --ops snapshot,snapshot_when && oracle/bin/harness fuzz --a "$JAVA_URL" --b "$OXHAVEN_URL" --ops snapshot,snapshot_when --seeds 10000
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The oracle harness has no `snapshot` or `snapshot_when` operation yet: the harness part of this gate stops with exit code 2 and says so. It needs an oracle task (scenario format, runner, corpus, fuzzer) before this task can close.
