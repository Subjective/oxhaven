## Scope

Evaluate typed expressions over Arrow arrays, one batch at a time, with Java's results for null, NaN, overflow, integer division and comparison across every type pair.

## Gate

```bash
cargo test -p oxhaven-expr eval && oracle/bin/harness formulas --check values --url "$OXHAVEN_URL"
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The `formulas` command and its checks are described in `oracle/README.md` ("Formula corpus").
