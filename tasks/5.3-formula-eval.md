## Scope

Evaluate typed expressions over Arrow arrays, one batch at a time, with Java's results for null, NaN, overflow, integer division and comparison across every type pair.

## Gate

```bash
cargo test -p oxhaven-expr eval && oracle/bin/harness formulas --check values --url "$OXHAVEN_URL"
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The `formulas` command is not in the harness yet; task 5.1 adds it. Until then this part of the gate stops with exit code 2.

## Notes

Done together with 5.2 on branch `task/5.2-formula-language`; see the notes there for the accepted language and the check against Java.

- Casts follow the `QueryLanguageFunctionUtils` cast methods: the null value of the source type becomes null, and a result equal to the null value of the target type is null.
- A ternary branch of a narrower type is widened without a null check, as javac does, so a null `int` in a `long` ternary is -2147483648 and not null.
- `==` between a primitive and a reference type, or between two unrelated reference types, is `eq(Object, Object)`: true only when both sides are null references.
- String conversion in `+` prints a null primitive as its null value and a null reference as `null`. `double` and `float` print as `Double.toString` and `Float.toString` of JDK 19 and later.
- String methods index UTF-16 code units. A null receiver or argument fails the evaluation, as Java's `NullPointerException` does. A result that would hold half of a surrogate pair fails by name, because an Arrow string cannot hold it; Java sends `?`.
- `&&`, `||` and `?:` evaluate an operand only for the rows that need it. A null Boolean condition fails the evaluation.
- The `oracle/bin/harness formulas` part of the gate was not run: the command does not exist yet.
