# 5.4 Built-in function library

- **Status:** open
- **Track:** C
- **Needs:** 5.3
- **Owns:** `crates/oxhaven-expr/src/functions/`

## Read

Paths are in the reference repository at the tag pinned in `oracle/REFERENCE.md`.

- `engine/function/src/main/java/io/deephaven/function`
- `engine/time/src/main/java/io/deephaven/time/DateTimeUtils.java`

## Scope

The functions formulas can call without imports: the `io.deephaven.function` numeric, statistics, sort, search, parse and cast families and the `DateTimeUtils` time functions. Port by family; read only the family you are porting. Register each under the same name and overloads as Java.

## Gate

```bash
cargo test -p oxhaven-expr functions && python oracle/run.py formulas --check functions
```
