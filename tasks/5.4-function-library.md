# 5.4 Built-in function library

- **Status:** in review
- **Track:** C
- **Needs:** 5.3
- **Owns:** `crates/oxhaven-expr/src/functions/`

## Read

Paths are in the reference repository at the tag pinned in `oracle/REFERENCE.md`.

- `engine/function/src/main/java/io/deephaven/function`
- `engine/time/src/main/java/io/deephaven/time/DateTimeUtils.java`

## Scope

The functions formulas can call without imports: the `io.deephaven.function` numeric, statistics, sort, search, parse and cast families and the `DateTimeUtils` time functions. Port by family; read only the family you are porting. Register each under the same name and overloads as Java.

## Gate

```bash
cargo test -p oxhaven-expr functions && oracle/bin/harness formulas --check functions --url "$OXHAVEN_URL"
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The `formulas` command and its checks are described in `oracle/README.md` ("Formula corpus").

## Notes

Implemented (`crates/oxhaven-expr/src/functions/`), each algorithm once over the numeric types:

- Constants: `QueryConstants` (`NULL_*`, `MIN_*`, `MAX_*`, `NAN_*`, `*_INFINITY_*`, the `_BOXED` ones as primitives), the time units of `DateTimeUtils` (`SECOND`, `DAY`, ...), `PI`, `E`, `DEFAULT_SCALE`.
- Numeric: `abs`, `signum`, `round`, `ceil`, `floor`, `rint`, `sqrt`, `exp`, `expm1`, `log`, `log10`, `log1p`, `pow`, the trigonometric and hyperbolic functions, `toDegrees`, `toRadians`, `isNaN`, `isInf`, `isFinite`, `min`, `max`, `clamp`, `lowerBin`, `upperBin`, `replaceIfNaN`, `replaceIfNullNaN`, `replaceIfNonFinite`.
- Basic and logic: `isNull`, `replaceIfNull`, `inRange` (numbers), `in`, `ifelse`, `and`, `or`.
- Parse: `parseByte`, `parseShort`, `parseInt`, `parseLong`, `parseBoolean` of one `String`.
- Operator functions of `QueryLanguageFunctionUtils`: `plus`, `minus`, `multiply`, `divide`, `remainder`, `eq`, `less`, `lessEquals`, `greater`, `greaterEquals`, `binaryAnd`, `binaryOr`, `xor`, `negate`, `not`, `byteCast` ... `doubleCast`.
- Time: `epochNanos`, `epochNanosToInstant`, `plus`/`minus` of an `Instant` and nanoseconds (also as `T + n`, `T - n`), `minus(Instant, Instant)` (also `T - T`), `diffNanos`, `isBefore`, `isBeforeOrEqual`, `isAfter`, `isAfterOrEqual`, `lowerBin`/`upperBin` of an `Instant`.
- `String#equalsIgnoreCase`.

Every other default import (`functions/names.rs` lists all 392) is refused by name as unsupported: the vector, statistics, sort and search families and everything else that takes or returns an array (no array column types here yet), the calendar, time zone, `LocalDate`, `Duration` and formatting functions, `now`/`today` and the random functions, the `Exact` family, `compare`/`compareTo`, `parseFloat`/`parseDouble`, the unit conversions (`nanosToMillis`, `epochMillis`, `diffSeconds`, ...), and `cbrt` and `hypot` (not correctly rounded in Java, and not among the functions the harness compares with a tolerance). A name that is not a default import is a type error.

Overloads follow what Java 42.9 answered, recorded in `crates/oxhaven-expr/tests/data/java_functions.json` (5182 calls: every function here over every argument type) and `java_additions.json`; the rules are in the module documentation of `functions/mod.rs`.

Tests: `tests/formulas/tagged.rs` runs `oracle/corpus/formulas/cases` (6309 cases: 3797 agree, 0 differ, 1821 refused and pinned in `tests/data/corpus_refused.txt`, 691 not run because Java does not treat them as formulas or fails in their setup); `tests/formulas/recorded.rs` runs the three recordings.

Gate: `cargo test -p oxhaven-expr functions` passes. `oracle/bin/harness formulas --check functions` was not run: it needs a running Oxhaven server that evaluates formulas.
