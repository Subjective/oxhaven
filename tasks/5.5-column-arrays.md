## Scope

`Column_[i-1]`-style access and the `i`, `ii` and `k` variables, including what Java returns out of range, which formulas Java refuses on refreshing tables, and how modifications propagate to dependent rows when ticking.

## Gate

```bash
cargo test -p oxhaven-expr arrays && oracle/bin/harness formulas --check arrays --url "$OXHAVEN_URL"
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The `formulas` command is not in the harness yet; task 5.1 adds it. Until then this part of the gate stops with exit code 2.
