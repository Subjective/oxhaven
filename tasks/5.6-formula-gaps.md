## Scope

The formulas that Java computes and `oracle/bin/harness formulas --check arrays` reported as refused when 5.5 merged: time literals with a zone name, durations and periods added to an `Instant`, `now()`, the random numbers, operators on vectors and arrays, and a null cast to an array type. Also the static `select` that 5.5 refuses although Java computes it.

## Gate

```bash
cargo test -p oxhaven-expr gaps && oracle/bin/harness formulas --check arrays --url "$OXHAVEN_URL"
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The `formulas` command and its checks are described in `oracle/README.md` ("Formula corpus").
