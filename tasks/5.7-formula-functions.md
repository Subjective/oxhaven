## Scope

The formulas that Java computes and the groups of `oracle/bin/harness formulas --check <group>` reported as refused when 5.6 merged: static calls (`String.valueOf`, `Long.toString`, `DateTimeUtils.now()`, `java.lang.Math`), a null literal as an operand, the time functions that were never ported, and the literals whose type is no column type where they are arguments. A formula whose result column would have a type that is no column type stays refused; so do the Boolean column array `Z2_` and the comparisons of arrays.

## Gate

```bash
cargo test -p oxhaven-expr statics && for group in accept-reject values functions arrays chains outside; do oracle/bin/harness formulas --check $group --url "$OXHAVEN_URL"; done
```

`$OXHAVEN_URL` and `$JAVA_URL` are described in `tasks/README.md`. The `formulas` command and its checks are described in `oracle/README.md` ("Formula corpus").
