# 6.0 Web IDE acceptance test and server requirements

- **Status:** in review
- **Track:** oracle
- **Needs:** none
- **Owns:** `oracle/ide/`

## Read

- `oracle/ide/README.md`: how the test runs and how it reads the grid.
- `oracle/ide/REQUIREMENTS.md`: what the web IDE asks of a server, as observed on Java 42.9.
- `oracle/ide/traces/`: the decoded recordings the requirements were written from.
- The web IDE itself is not in the reference repository: it ships in the wheel as
  `deephaven_server/jars/deephaven-web-42.9.jar` (`META-INF/resources/{ide,iframe,jsapi}`).

## Scope

The owner's acceptance criterion as a test: open the Deephaven web IDE served by a server,
authenticate, and see a static and a ticking table. A Playwright test (Node, headless Chromium)
that takes a server URL and key and covers the routes that work on Java: the Panels list
(`panels`), the embedding URL (`iframe`), the JS API (`jsapi`) and, for a server with a console,
typed commands (`console`). Tooling to record every request of a run and to answer chosen gRPC
calls `UNIMPLEMENTED`, and the requirements document written from those recordings.

Not part of it: any change to the Rust crates. Serving the static files, the websocket transport
and the calls listed in `REQUIREMENTS.md` belong to server tasks; see Notes.

## Gate

The test needs a server that already holds the two tables of `oracle/ide/expected.json`,
`ide_static` and `ide_ticking`, and lists them in `ApplicationService/ListFields`, and that
serves the web IDE files under `/ide/`, `/iframe/` and `/jsapi/`.

Against Java (closes this task):

```bash
oracle/ide/bin/start-java-ide.sh 10500 && node oracle/ide/ide-test.js --url dh+psk://oxhaven@127.0.0.1:10500 --routes panels,iframe,jsapi,console; oracle/bin/stop-java.sh 10500
```

Against Oxhaven (the acceptance gate of M6; no console is needed):

```bash
node oracle/ide/ide-test.js --url "$OXHAVEN_URL"
```

`$OXHAVEN_URL` is described in `tasks/README.md`, for example
`dh+psk://oxhaven@127.0.0.1:10100`. The default routes are `panels,iframe,jsapi`. The exit
status is 0 when every route passed, 1 when a route failed, 2 when the test could not run. Each
run writes screenshots, a trace per route and `report.json` to `oracle/ide/.out`. While the
server is being built, `--routes jsapi` is the route that needs the least: no IDE application,
no `GetConsoleTypes`, no `StorageService`.

The test must also fail when it should; on Java:

```bash
node oracle/ide/ide-test.js --url dh+psk://wrong@127.0.0.1:10500        # exit 1, UNAUTHENTICATED
oracle/ide/bin/start-java-ide.sh 10501 scope --no-tables && node oracle/ide/ide-test.js --url dh+psk://oxhaven@127.0.0.1:10501   # exit 1, tables not listed
```

## Notes

- No `unported!` calls: nothing in the Rust workspace changed.
- Needs `require('playwright')` and its Chromium to resolve; the test installs nothing. CI has
  no job for it, and a pull request touching `oracle/` needs the `oracle-change` label.
- Work the ledger does not have yet, from `REQUIREMENTS.md`:
  - Serving the files of `deephaven-web-42.9.jar` over HTTP on the gRPC port. No task owns it.
  - The `grpc-websockets-multiplex` websocket transport. Over plain http the IDE and the JS
    API use nothing else; the gRPC-web and Open/Next variants of 2.6 are used only over https.
  - `ConsoleService/GetConsoleTypes` answering an empty list: `UNIMPLEMENTED` stops the IDE
    application (not the JS API).
  - `ApplicationService/ListFields` (a stream that stays open) with application fields, and a
    way for the Oxhaven process to hold `ide_static` and `ide_ticking` at startup.
  - `SessionService/TerminationNotification` has to stay pending: an answer, or
    `UNIMPLEMENTED`, makes the IDE show "Server shutdown" or reconnect in a loop.
- Not determined: listed at the end of `REQUIREMENTS.md`. The Groovy console commands of
  `expected.json` were never run.
