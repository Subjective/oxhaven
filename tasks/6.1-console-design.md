## Scope

Decide how Oxhaven runs user Python without a JVM, write the decision down, and prove it
with a thin slice: `GetConsoleTypes`, `StartConsole`, `ExecuteCommand` running real Python
that imports `deephaven`, variables published as scope fields, output captured, errors
reported. Then write the follow-on tasks (6.2 to 6.18, 7.1 to 7.11).

The decision is in `docs/CONSOLE.md`: CPython embedded with PyO3 behind the cargo feature
`python`, an own `deephaven` package compiled into the binary, and every table operation
run through the table service handler of that operation.

## Gate

```bash
cargo test -p oxhaven-server --lib -- console:: && cargo test -p oxhaven-server --features python --lib -- console:: && oracle/console/check.sh "$OXHAVEN_ADDRESS"
```

The first part runs in every build, the second needs a Python 3 with a shared libpython, and
the third needs a server built with `--features python` that was just started
(`oracle/console/README.md`); `$OXHAVEN_ADDRESS` is its `host:port`. The IDE check is
`node oracle/ide/ide-test.js --url "$OXHAVEN_URL" --routes console` against the same server
started with `--web-root`.

## Notes

- No contract changes. No `unported!` calls.
- New dependencies, both optional and only built with the feature: `pyo3` 0.27 and
  `prost-reflect` 0.16 (already in the lock file through `protox`).
- Outside the paths above: `Applications::scope_changed` (`app/fields.rs`),
  `table::run_local` (`table/mod.rs`), `ServerState::console` and `::logs`, `--console` in
  `main.rs`, `TestServer::start_with`, and the job `python-console` in
  `.github/workflows/ci.yml`.
- What is stubbed and how the answers differ from Java: the two tables at the end of
  `docs/CONSOLE.md`.
- Seen on Java and worth knowing: a command on a console id that is never exported waits
  for ever (no error); a script error is an `OK` answer; Java's own log reaches
  `SubscribeToLogs` twice, once per level and once as the `STDERR` line of its console
  appender, so the IDE's log panel shows every stack trace of a failed command.
