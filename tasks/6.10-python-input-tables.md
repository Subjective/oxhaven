Paths are in the reference repository at the tag pinned in `oracle/REFERENCE.md`. Read the reference package for names, signatures, argument conversion and error

    - `py/server/deephaven/table_factory.py`: `InputTable`, `input_table`,
      `DynamicTableWriter`, `ring_table`, `function_generated_table`.
    - `crates/oxhaven-server/src/inputtable/` and `table/ops/create_input_table.rs`.

## Scope

`input_table` (append-only and keyed, from column definitions or an initial table) and
`InputTable.add`, `delete`, their async forms, `key_names`, `value_names`, through the
code the input table service uses. `DynamicTableWriter` over an append-only input
table. `ring_table`, `function_generated_table` and `TableReplayer` if the engine has the
operators; otherwise they raise and are listed.

## Gate

```bash
cargo test -p oxhaven-server --features python --lib -- console:: && oracle/bin/harness replay-scripts --url "$OXHAVEN_URL" --scripts input_
```

`$OXHAVEN_URL` is a server built with `--features python` (`tasks/README.md`,
`oracle/console/README.md`). `replay-scripts` and the recorded scripts come from task 6.3; until
it is merged, run the cargo part and report the other as not run.
