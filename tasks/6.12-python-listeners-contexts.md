## Scope

- `listen(table, callback)` and `TableUpdate` (`added()`, `removed()`, `modified()`,
  `modified_prev()` as dictionaries of numpy arrays, or of lists without numpy), run on
  the cycle thread under the lock rule of 6.11; `replay_initial`; `stop`.
- `update_graph.shared_lock`/`exclusive_lock` as context managers and decorators over the
  engine's graph lock.
- `liveness_scope` and `execution_context`: Rust has no liveness scopes; tables live as
  long as something holds them. Provide the names as context managers that do what is
  observable (a table released when the scope closes can no longer be used by Python)
  and say in Notes what is not observable.
- `Table.await_update`.
