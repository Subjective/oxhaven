## Scope

Record, with the tracing of `oracle/ide`, what the IDE calls on Java for each flow below,
add a route to `ide-test.js` per flow, and make each pass on Oxhaven:

- the File Explorer: create, open, save, rename, move and delete a notebook
  (`StorageService` `FetchFile`, `SaveFile`, `MoveItem`, `CreateDirectory`,
  `DeleteItem` over a real directory, `--storage-root`), and "run" and "run selected" from
  a notebook;
- the Log panel and the command history panel;
- a table created in the console, then sorted, filtered and scrolled from the grid
  (the `Batch` operations no earlier run made);
- a command that fails, and a command that removes a variable whose panel is open;
- reconnecting after the server restarts.

Anything a flow needs that belongs to another task is listed with that task's id rather
than built here.

## Gate

```bash
node oracle/ide/ide-test.js --url "$OXHAVEN_URL" --routes console,notebook,grid,errors
```

against a server built with `--features python` and started with `--web-root` and
`--storage-root`. Each new route must also pass on Java and fail on a server without a
console.

  such a name cannot be created from the IDE); `MoveItem` between file systems
  (`sun.nio.fs.UnixFileSystem#move`); every call but `ListItems` on a server started
  without `--storage-root`.
