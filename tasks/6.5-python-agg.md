# 6.5 Python API: aggregations

- **Status:** open
- **Track:** P
- **Needs:** 6.4
- **Owns:** `crates/oxhaven-server/python/deephaven/agg.py`, the aggregation methods of `crates/oxhaven-server/python/deephaven/table.py`, script scenarios `agg_*`

## Read

- `docs/CONSOLE.md`: the design, and the rule that a table operation goes through the table
  service handler (`deephaven/_engine.py`, `table_op`).
- `crates/oxhaven-server/python/deephaven/table.py` and `table_factory.py`: how the existing methods are written.

Paths are in the reference repository at the tag pinned in `oracle/REFERENCE.md`. Read the reference package for names, signatures, argument conversion and error
message texts. Do not copy its code or docstrings: it is not open source (`docs/CONSOLE.md`).

    - `py/server/deephaven/agg.py`: every function and the `Aggregation` class.
    - `py/server/deephaven/table.py`: `group_by`, `agg_by`, `agg_all_by`, `partitioned_agg_by`
      and the dedicated methods (`count_by`, `first_by`, `last_by`, `sum_by`, `abs_sum_by`,
      `weighted_sum_by`, `avg_by`, `weighted_avg_by`, `std_by`, `var_by`, `median_by`, `min_by`,
      `max_by`, `head_by`, `tail_by`).
    - `crates/oxhaven-server/src/table/ops/aggregate.rs`: the three request shapes the
      handlers take (`Aggregate`, `AggregateAll`, `ComboAggregate`).

## Scope

`from deephaven import agg` with every function of the reference module, each returning
an object that renders itself as the `Aggregation` message of the table service, and the
table methods above. `agg_by` with `preserve_empty` and `initial_groups`.
`agg.formula`, `agg.partition` and whatever else the handlers answer `UNIMPLEMENTED` to
raise with that text.

Not `partitioned_agg_by` (7.6).

## Gate

```bash
cargo test -p oxhaven-server --features python --lib -- console:: && oracle/bin/harness replay-scripts --url "$OXHAVEN_URL" --scripts agg_
```

`$OXHAVEN_URL` is a server built with `--features python` (`tasks/README.md`,
`oracle/console/README.md`). `replay-scripts` and the recorded scripts come from task 6.3; until
it is merged, run the cargo part and report the other as not run.
