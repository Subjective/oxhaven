# 6.7 Python API: joins

- **Status:** open
- **Track:** P
- **Needs:** 6.4
- **Owns:** the join methods of `crates/oxhaven-server/python/deephaven/table.py`, `multi_join` in `crates/oxhaven-server/python/deephaven/table.py`, script scenarios `join_*`

## Read

- `docs/CONSOLE.md`: the design, and the rule that a table operation goes through the table
  service handler (`deephaven/_engine.py`, `table_op`).
- `crates/oxhaven-server/python/deephaven/table.py` and `table_factory.py`: how the existing methods are written.

Paths are in the reference repository at the tag pinned in `oracle/REFERENCE.md`. Read the reference package for names, signatures, argument conversion and error
message texts. Do not copy its code or docstrings: it is not open source (`docs/CONSOLE.md`).

    - `py/server/deephaven/table.py`: `natural_join`, `exact_join`, `join`, `aj`, `raj`,
      `range_join`, `NaturalJoinType`, `MultiJoinInput`, `MultiJoinTable`, `multi_join`,
      `keyed_transpose`.
    - `crates/oxhaven-server/src/table/ops/join.rs`, `crossjoin.rs`, `asof.rs`,
      `range_join.rs`, `multi_join.rs`.

## Scope

The join methods with the reference's argument forms (`on` and `joins` as a string or a
sequence, `type`/`NaturalJoinType`, `aj`/`raj` match expressions, `range_join` with its
aggregations from 6.5), `multi_join` in both of its call forms. `keyed_transpose` if its
engine operation exists; otherwise it raises and is listed.

## Gate

```bash
cargo test -p oxhaven-server --features python --lib -- console:: && oracle/bin/harness replay-scripts --url "$OXHAVEN_URL" --scripts join_
```

`$OXHAVEN_URL` is a server built with `--features python` (`tasks/README.md`,
`oracle/console/README.md`). `replay-scripts` and the recorded scripts come from task 6.3; until
it is merged, run the cargo part and report the other as not run.
