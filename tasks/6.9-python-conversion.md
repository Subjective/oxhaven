## Scope

Data crossing between the engine and Python libraries, in the process, without copying
where Arrow allows it: a consistent snapshot of a table as Arrow record batches exported
through the C stream interface, and the reverse for `to_table`. On top of it `to_pandas`
(with `dtype_backend` and `conv_null`), `to_numpy`, `to_arrow` and their `to_table`s,
with the reference's null conventions per type. The libraries are optional: without
numpy, pandas or pyarrow importable the functions raise as the reference does.

Needs 6.16 because the libraries have to be importable by the embedded interpreter, in
tests and in CI.

## Notes

- Sized for one agent context. If the list does not fit, finish the part that users type
  first, list the rest here, and stop.
- A method whose engine operation is missing raises `DHError` naming the Java method, from
  the handler's `UNIMPLEMENTED`; it is never left out silently and never approximated.
- Done: `to_pandas`, `to_numpy`, `to_arrow` and the three `to_table`s; the row readers
  (`iter_dict`, `iter_tuple`, `iter_chunk_dict`, `iter_chunk_tuple`) give instants and arrays.
- Refused, each naming the Java method:
  - a vector column (a grouped column) in the row readers, `to_numpy` and
    `to_pandas(dtype_backend=None)`: `PythonTableDataReader#readChunkColumnMajor`. Java hands
    out the `io.deephaven.vector.Vector` object. `to_arrow` and the other backends of
    `to_pandas` give it as a list.
  - `arrow.to_table` of an Arrow type an upload refuses (unsigned 8, 32 and 64 bit integers,
    half floats, timestamps not of nanoseconds, dates, times, durations, decimals, binary):
    `BarrageUtil#convertArrowSchema`, `BarrageUtil#getDefaultType` or
    `DefaultChunkReaderFactory#newReader`. Java converts some of these.
    `pandas.to_table` raises the same for an Arrow backed column of such a type.
  - `arrow.read_feather`: `ArrowWrapperTools#readFeather`.
- `to_arrow` gives every row in one record batch; Java gives batches of 4096 rows and more.
- Left: a `deephaven.time` value as a query scope variable in a formula (the scope has no
  instant value, `crates/oxhaven-server/src/app/scope.rs`, not owned here).
