## Scope

The design is `docs/STORAGE.md`: a table read from storage is a list of locations
(`oxhaven-engine::source`), each read on demand a column and a row group at a time, with
Java's row keys. CSV and Kafka do not use it; the document says what they use instead.

The first slice, which this task is: `deephaven.parquet.read` of one file and of a
directory of files, for the column types Oxhaven has, uncompressed and with the `GZIP`
and `LZ4_RAW` codecs. What it leaves for later slices is under Notes.

## Notes

- Changes `oracle/`: the pull request needs the `oracle-change` label. Nine script
  scenarios `parquet_*`, recorded from Java; five are clean in the baseline and four
  differ, each by what a later slice ports.
- No change to `crates/oxhaven-contracts`.
- No `unported!` call. What is not ported is a `ReadError::NotPorted` that names the Java
  method, and reaches Python as a `NotImplementedError` inside the `DHError`.
- Later slices, each small enough for one task, in the order the scenarios suggest:
  1. Column names Java makes legal (`parquet_read_names`).
  2. Partition directories `key=value` (`parquet_read_partitioned`). Needs a flag for a
     partitioning column on the contracts' `ColumnDefinition`, a protected change.
  3. `_metadata` and `_common_metadata` files (the same scenario).
  4. Refreshing directories (the same scenario); the first table here that ticks.
  5. The types without a column type: `LocalDate`, `LocalTime`, `LocalDateTime`,
     `BigDecimal`, `BigInteger`, `byte[]` (`parquet_read_more_types`). They need column
     types first, which is not a Parquet question.
  6. Snappy, Zstandard and Brotli (`parquet_read_codecs`). The Rust crates that decode
     them are BSD-3-Clause, which the project has not accepted; Snappy is what Java
     writes by default, so the owner decides this one first.
  7. `table_definition`, `special_instructions`, paths with a URI scheme, `impl/dataindex`.
- `docs/STORAGE.md`, "Differences from Java", lists what this slice does otherwise than
  Java besides refusing.
