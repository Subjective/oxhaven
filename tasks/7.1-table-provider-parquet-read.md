## Scope

**Needs its own design first.** This file marks the area so the plan has no blank; the architect of M7 replaces it with sized tasks. The first deliverable is a short design document, as `docs/CONSOLE.md` is for the console.

Questions for the design: whether a stored table is a column source over Arrow arrays
read on demand (the contracts' sources are Arrow already) or is loaded whole first; how
partitioned directory layouts (flat, key-value, metadata files) map to row keys and to a
partitioning column; which Parquet-to-Deephaven type mappings and codecs Java defines
(`deephaven:` metadata in the file footer); whether refreshing directories are in scope;
and which Rust Parquet reader is used (the `parquet` crate of arrow-rs is the default
assumption). Then `read`, `read_table`-style entry points in `deephaven.parquet`.
