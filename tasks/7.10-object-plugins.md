## Scope

**Needs its own design first.** This file marks the area so the plan has no blank; the architect of M7 replaces it with sized tasks. The first deliverable is a short design document, as `docs/CONSOLE.md` is for the console.

Server-side objects other than tables: `FetchObject` and `MessageStream`, object types
registered by Python plugins found through entry points, the type names in `ListFields`,
and the JS plugin manifest the IDE loads. Plugins are Python packages written against
`deephaven-plugin` and often against the `deephaven` package, so this is where
compatibility of the reimplemented package is tested by code we did not write
(`deephaven-plugin-ui`, `plotly-express`). Design questions: which plugin APIs touch jpy
types, and how exported references inside a message are tracked.

## Gate

Not defined until the design exists. It will include recorded Java results in `oracle/corpus` for every operation, as for the operators.
