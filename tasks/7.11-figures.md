## Scope

**Needs its own design first.** This file marks the area so the plan has no blank; the architect of M7 replaces it with sized tasks. The first deliverable is a short design document, as `docs/CONSOLE.md` is for the console.

`docs/SOURCE_MAP.md` marks Java's `Plot` out of scope. Decide whether the legacy
`deephaven.plot` API (a large generated surface that builds a `FigureDescriptor` with
table references and downsampling) is worth building, or whether figures come only
through the plugin route (`deephaven.plot.express`), which needs 7.10 and
`RunChartDownsample` and nothing else of `Plot`. Recommend one with the owner.

## Gate

Not defined until the design exists. It will include recorded Java results in `oracle/corpus` for every operation, as for the operators.

## Notes

- The design is `docs/FIGURES.md`: the legacy `deephaven.plot` API is built in Python for
  plots whose data is a table, and the server holds and serves the finished descriptor.
- Done: XY (line, scatter and the other styles), error bars of one series, histogram,
  category, category histogram, OHLC, pie, treemap, several series, charts and axes, twins,
  `by` with a partitioned table; the `Figure` object type. The web client opens the series
  of a `by` plot through `OpenDoPut`/`NextDoPut` of `BrowserFlightService`, which task 7.8
  added while this one ran; the copy made here was dropped in the merge.
- The gate is `cargo test -p oxhaven-server --features python figure`: 173 pieces of
  plotting code against what Java 42.9 answered, recorded in
  `crates/oxhaven-server/src/console/python/fixtures/figures-java-42.9.jsonl`. Nothing was
  added to `oracle/corpus`: a figure is no table operation, and the harness has no route for
  an object.
- Refused, with the Java method of each: `docs/FIGURES.md`, "Refused".
- Not started: JS plugins (`CallbackAdapter#registerJsPlugin`, `/js-plugins/manifest.json`).
  `deephaven-plugin-plotly-express` and `deephaven-plugin-ui` were tried and not made to
  work; `docs/FIGURES.md`, "The plugin route: a trial", lists what each is missing. The one
  change from the trial: a module that a distribution adds to the `deephaven` package is
  found.
