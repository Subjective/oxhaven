## Scope

The second slice of `docs/STORAGE.md` ("The second slice"): what 7.1 left for later that
four script scenarios ask for.

- Five column types for Java's objects (`BigDecimal`, `BigInteger`, `LocalDate`,
  `LocalTime`, `LocalDateTime`), `byte[]` as `Array` of `Byte`, and a group with one
  field; a formula can print them and test them for null.
- Column names changed as `NameValidator#legalizeColumnName` changes them.
- Partition directories `key=value` with partitioning columns, `_metadata` files, and a
  directory that is followed (`is_refreshing=True`), the first stored table that ticks.
- Which operations keep a column partitioning, and `TableDefinition` in Python saying so.

Not in scope: Brotli (`parquet_read_codecs`), `table_definition`,
`special_instructions`, paths with a URI scheme, data indexes, writing partitioned tables.
