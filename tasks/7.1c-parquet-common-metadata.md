## Scope

The third slice of 7.1's list ("`_metadata` and `_common_metadata` files"): a directory
whose partitioning columns only `_common_metadata` knows, which is what
`write_partitioned(..., generate_metadata_files=True)` of 7.2b leaves. 7.1b and 7.2b
refused it with `ReadError::NotPorted` naming `ParquetMetadataFileLayout#create`. Read
it as Java does, with `file_layout=ParquetFileLayout.METADATA_PARTITIONED` and with the
layout inferred from the directory or from the path of either metadata file.

Not in scope: `table_definition`, data indexes, refreshing (Java refuses it for this
layout), reading only the row groups a metadata file lists of a file.
