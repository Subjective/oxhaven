## What the write path refused when this task began

Each line was probed against the reference (Deephaven 42.9) with the script scenario
`parquet_write_unported` and by hand; "Java" says what it answered.

| Refusal | Where | Java |
| --- | --- | --- |
| A column of type `BigDecimal`, `BigInteger`, `LocalDate`, `LocalTime`, `LocalDateTime` (`TypeInfos#getTypeInfo`) | `write.rs`, `primitive` | Writes `DECIMAL(precision, scale)` over `BINARY` with the precision and scale of the values of every table of the write, `DECIMAL(1, 0)` for a `BigInteger`, `DATE`, `TIME(nanos, adjusted)`, `TIMESTAMP(nanos, not adjusted)` |
| `write_partitioned` of a table with partitioning columns (`ParquetTools#writeKeyValuePartitionedTable`) | `parquet.py` | One file for each key under `key=value` directories, named by `base_name` (`{uuid}` by default, with `{i}` and `{partitions}`); files that are there stay unless they have the name of a new one |
| `write_partitioned` of a partitioned table | `parquet.py`, which took a `Table` only | The same, with the key columns of the partitioned table |
| `generate_metadata_files=True` (`ParquetMetadataFileWriterImpl#writeMetadataFiles`) | `write.rs`, `WriteOptions::check` | `_metadata` (every row group, with the path of its file) and `_common_metadata` (the schema, with the partitioning columns first) in the directory of the files, which must be one directory |
| `index_columns` that names columns (`ParquetInstructions.Builder#addAllIndexColumns`) | `write.rs`, `WriteOptions::check` | `.dh_metadata/indexes/<columns>/index_<columns>_<file>` beside each file, with a `dh_row_set` column written with `RowSetCodec`, and `dataIndexes` in the footer |
| `special_instructions` (`ParquetInstructions.Builder#setSpecialInstructions`) | `parquet.py` | Instructions for S3 |
| A destination with a URI scheme (`SeekableChannelsProviderLoader#load`) | `write.rs`, `destination` | `file:` is the local file system, with the path decoded; `s3:` and others go to their store |
| `LZO` (`DeephavenCompressorAdapterFactory#getByName`) | `write.rs`, `compression` | LZO pages |
| A codec named by its class | `write.rs`, `compression` | The classes its codec factory holds, with their exact names |
| `codec_name` in a column instruction (`ParquetInstructions.Builder#addColumnCodec`) | `write.rs`, `WriteOptions::check` | The cells through the object codec, as `BINARY` |
| An empty name for the file in a column instruction (`ParquetInstructions.Builder#addColumnNameMapping`) | `write.rs`, `WriteOptions::check` | A column without a name, which no reader takes |
| A column whose cells hold vectors or arrays (`TypeInfos#getCodecAndArgs`) | `write.rs`, `schema_field` | The cells serialized by `SerializableCodec` |
| A column with another type in `table_definition` than in the table (`TransferObject#create`) | `write.rs`, `plan` | The table's values under the definition's Parquet type where the storage is the same (an `int` as a `short`), a failure otherwise |
| `by_groups` on a vector or array column (`RowGroupTableIteratorVisitor.SplitByGroupsIterator#next`) | `write.rs`, `runs` | Groups by the cells |
