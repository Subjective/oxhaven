# 7.3 Reading and writing CSV

- **Status:** in review
- **Track:** C
- **Needs:** 6.8
- **Owns:** `crates/oxhaven-csv/` (new), `deephaven/csv.py`

## Read

Paths are in the reference repository at the tag pinned in `oracle/REFERENCE.md`.

- `extensions/csv/src/main/java/io/deephaven/csv/CsvTools.java`
- the `deephaven-csv` library's type inference rules (a separate Deephaven project under
  Apache 2.0; check its licence text before reading its source for more than behavior)
- `py/server/deephaven/csv.py`

## Scope

The design is `docs/CSV.md`: Java's reader is reimplemented cell by cell in
`crates/oxhaven-csv`, with no CSV crate, because the type of a column depends on how the
cells are cut and on the order in which Java's chain of parsers meets them.

`deephaven.csv.read` with every argument of the reference, `deephaven.csv.write`, and
`deephaven.read_csv` and `deephaven.write_csv` for them. A read makes a static in-memory
table with the column names, types and values Java gives the same file.
