## Scope

**Needs its own design first.** This file marks the area so the plan has no blank; the architect of M7 replaces it with sized tasks. The first deliverable is a short design document, as `docs/CONSOLE.md` is for the console.

Blink, append-only and ring tables fed from topics, with the key and value specs users
name (simple, JSON, Avro, Protobuf, raw). The engine side is the general stream-to-table
adapter, which `table_publisher` and `DynamicTableWriter` also want; design that first.
Needs a decision on the client library (`rdkafka` links a C library; a pure Rust client
has fewer features) and on how CI gets a broker.
