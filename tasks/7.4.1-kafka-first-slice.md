## Scope

The design of Kafka support, `docs/KAFKA.md`: what Java offers, the client library and
its licences, the engine side, how tests get a broker, and the tasks that replace 7.4 and
7.5.

A first slice: `deephaven.stream.kafka.consumer.consume` into blink, append-only and ring
tables, with simple and JSON specs, the common columns and their properties, partitions,
and offsets from the beginning, the end or a number, over plaintext connections. Compared
with the Java reference consuming the same broker. Everything else is refused by the name
of the Java method.

## Gate

```bash
cargo test -p oxhaven-kafka

crates/oxhaven-kafka/tests/broker.sh        # needs Docker; not run by CI yet
```

Nothing is recorded in `oracle/corpus`: a consumed topic depends on a broker, which the
replay gate does not have. A corpus replayed through a scripted record source is task
7.4.6.

## Notes

- **librdkafka is not added.** The owner allowed it on 2026-11-16 for BSD-2-Clause, MIT
  and Apache-2.0. Its smallest build also compiles files under BSD-3-Clause (`snappy.c`,
  `rdsysqueue.h`) and the zlib licence (`crc32c.c`, `tinycthread.c`,
  `tinycthread_extra.c`, `nanopb/`). The slice uses the `kafka-protocol` crate (MIT OR
  Apache-2.0, with `crc`, `crc-catalog` and `crc32c`, the same) and a client of its own
  behind a trait. `docs/KAFKA.md`, "The client library" and "For the owner's ruling".
- No change to `crates/oxhaven-contracts`, `oracle/` or `PARITY.md`.
- No `unported!` call. What is not ported is a `KafkaError::NotPorted` that names the
  Java method; it reaches Python as a `NotImplementedError` inside the `DHError`, or
  fails the table when only a record shows it. `docs/KAFKA.md`, "Refused, by Java method".
- Compared with Java 42.9 by hand: both servers on one broker (`apache/kafka:3.9.1` in
  Docker), 21 cases and one run with records arriving. `docs/KAFKA.md`, "Differences from
  Java seen in the probes". The probe scripts are not in the repository.
- Five items wait for the owner (`docs/KAFKA.md`, "For the owner's ruling"): the client's
  licence, row order across partitions within one poll, rows before a bad record,
  consumer properties without effect, text that is not UTF-8.
- Outside the owned paths: `console/python/kafka.rs` and its two lines in
  `console/python/mod.rs`, and the optional dependency in the server's `Cargo.toml`
  (part of the `python` feature).
- CI: the default jobs run everything but the broker tests. The job that runs
  `tests/broker.sh` is written out in `docs/KAFKA.md` and not added.
- The engine pieces the slice had to build for itself (a stream table without the
  `InputTable` attribute, appending instead of `blink_to_append_only`) are task 7.4.2.
