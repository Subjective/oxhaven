## Scope

The 7.5.2 row of `docs/KAFKA.md`, "Tasks": `producer.produce` with `topic_col`,
`partition_col` and `timestamp_col`, with Java's checks, their precedence over `topic` and
`partition`, and Java's texts; `producer.avro_spec` for the key and the value (a schema from
the registry by subject and version, `field_to_col_mapping`, `timestamp_field`,
`include_only_columns`, `exclude_columns`, `publish_schema` with `schema_namespace` and
`column_properties`), and records in Confluent's wire format, byte for byte as Java writes
them; the raw spec, if the reference's Python reaches it. The `kafka-broker` script gains an
Avro produce-then-consume round trip and the three column options.

Each behaviour is probed on the Java reference and on this server against the same broker
and a request-logging registry stub, and the records compared byte for byte.
