## Scope

**Needs its own design first.** This file marks the area so the plan has no blank; the architect of M7 replaces it with sized tasks. The first deliverable is a short design document, as `docs/CONSOLE.md` is for the console.

`docs/SOURCE_MAP.md` lists Java's row set containers as later work. It is performance
work with no behavior of its own, so by PORTING.md rule 5 it starts from a benchmark: say
which workloads (large sparse tables from 7.1) are slow with the present representation
before choosing a structure.

## Gate

Not defined until the design exists. It will include recorded Java results in `oracle/corpus` for every operation, as for the operators.

## Notes

The design is `docs/ROWSET.md`: the benchmark of the present representation, the structure
chosen, the measurements of both, and where the new one is slower.

Built: `oxhaven_rowset::BlockRowSet` (`crates/oxhaven-rowset/src/blocks`), with every
operation of the contract `RowSet`, and the benchmark `src/bin/rowset-bench.rs`.

Not built: the engine still uses the contract `RowSet`. Replacing it changes
`crates/oxhaven-contracts` (`RowSet::ranges` returns a slice, which fixes the representation),
so it is left to a contract-change pull request; `docs/ROWSET.md`, "Making it the engine's row
set", lists what that change touches and its gate.

Gate used, in place of the one this file leaves undefined:

```bash
cargo test -p oxhaven-rowset
OXHAVEN_TEST_SEEDS=full cargo test -p oxhaven-rowset
cargo run --release -p oxhaven-rowset --bin rowset-bench
```

There are no recorded Java results for row-set operations in `oracle/corpus`: a row set is not
visible on the wire. The differential test is against the contract `RowSet`, whose behavior the
ported Java tests of task 1.2 and the operator corpus already pin down.

No `unported!` calls were added.

Task 7.7b (`tasks/7.7b-rowset-swap.md`) has since made that contract change: the type is
`oxhaven_contracts::rowset::RowSet`, and the benchmark is an example of the crate
(`cargo run --release -p oxhaven-rowset --example rowset-bench`).
