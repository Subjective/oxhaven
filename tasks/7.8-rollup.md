## Scope

**Needs its own design first.** This file marks the area so the plan has no blank; the architect of M7 replaces it with sized tasks. The first deliverable is a short design document, as `docs/CONSOLE.md` is for the console.

A rollup is aggregations at every level of a key hierarchy, viewed through an expansion
state the client sends: the server snapshots only the expanded rows. The design has to
cover the view and expansion-table protocol, the Barrage subscription form the IDE uses
for it, node operations (sort, filter, format per level), and which aggregations are
allowed. The IDE's rollup UI is the acceptance test.
