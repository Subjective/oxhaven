# 8.1 End-to-end benchmark against Deephaven

- **Status:** in progress
- **Needs:** none
- **Owns:** `bench/`, `docs/BENCHMARK.md`, the `bench/` line of the layout table in `AGENTS.md`

## Scope

A first end-to-end benchmark of Oxhaven against Deephaven 42.9: a runner under `bench/` that
runs each case on two servers through the oracle's Python client, checks that both give the
same result, and writes a JSON file and a Markdown table; a first set of static cases at two
sizes and one ticking case; one measured run; `docs/BENCHMARK.md` with the method, the results
and a reading of them. No engine, server or oracle changes, and no tuning.

## Gate

`cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`,
`cargo test --workspace`, `scripts/check-commit-subjects.sh origin/main..HEAD`, and a complete
run of `bench/bench.py run` against both servers.
